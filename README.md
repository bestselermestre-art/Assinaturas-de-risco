## A Lógica de Alerta (O "Coração" do Escâner)
O escâner vai processar a matéria camada por camada. Se ele encontrar algo que bata com essa biblioteca entre a superfície e a água, ele trava a operação.

## Mapeamento Vertical:
Você não vê apenas o ponto A (areia) e o ponto B (água). Você vê o perfil estratigráfico. Isso é exatamente o que robôs em Marte fazem para evitar quebrar suas brocas em rochas excessivamente duras ou contaminar amostras.
